# 🎮 Interactive JavaScript Browser Game

Welcome to the **JavaScript_Game** repository! This is one of my **early training projects**, created to challenge myself by building a fully functional interactive game logic using core web technologies.

The project demonstrates dynamic canvas or DOM rendering, real-time control logic, and user interaction mechanics.

## 🚀 Live Demo
You can launch and play the game directly in your browser here:
👉 [Play on GitHub Pages](https://github.io)

## 💻 Tech Stack
The game relies entirely on native browser features without heavy external frameworks:
* **HTML5** — for creating the container layout and rendering frame.
* **CSS3** — for applying visual themes, menus, and layout styling.
* **JavaScript (Vanilla JS)** — for core engine mechanics, score calculation, movement logic, and player state updates.

## 🎯 Game Features & What I Practiced
Developing this browser-based experience helped me implement essential programming structures:
* **Game Loops & Timers:** Managing continuous visual frame updates or intervals to animate game components smoothly.
* **Interactive Event Handling:** Listening to user controls (like keyboard buttons, mouse actions, or clicks) to update actor placement.
* **Collision Detection / Logic:** Writing condition checks to verify when objects interact, targets are hit, or bounds are broken.
* **Dynamic Score Tracking:** Programmatically tracking and display updating game progression stats in real time.
